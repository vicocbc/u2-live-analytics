About the data, and the photos
Sources
setlist.fm: every U2 show and setlist, through the setlist.fm API (free for non-commercial use; data contributed by fans). MusicBrainz: albums, tracks and songs (CC0). The pipeline loads both weekly into Microsoft Fabric (Bronze → Silver → Gold) and this report reads the Gold warehouse through a Direct Lake model.
